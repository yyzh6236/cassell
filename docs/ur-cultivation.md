# UR 角色养成消耗

来源：用户于 2026-11-18 提供的 UR 养成表截图。
逐级数据保存在 `assets/js/cultivation-config.js`。在「UR养成」标签选择当前等级和目标等级，并填写已有材料，即可查看目标和后续各级的累计缺口。

## 计算口径

- 当前等级到目标等级，只累加途中各次升级的消耗。
- 碎片与「本体」列为同一需求的两种计量：每本体等价值100碎片，不重复相加。此处仅记录表中等价值，不额外推断游戏的兑换操作规则。
- 觉0→觉5消耗觉醒石；觉5→超5消耗超限石。两种石头分别统计。
- 首次获得觉0：表中列100碎片、1本体、0石头，单独记录，不包含在以觉0为起点的升级合计中。
- 此处记录升级消耗；原计算器 `CULTIVATE_REWARDS` 是升级获得的奖励，不作为消耗，也不在本次数据中抵扣。

## 逐级消耗

- 觉0→觉1：200碎片（2本体等价值）+ 2觉醒石。
- 觉1→觉2：200碎片（2本体等价值）+ 2觉醒石。
- 觉2→觉3：300碎片（3本体等价值）+ 3觉醒石。
- 觉3→觉4：300碎片（3本体等价值）+ 3觉醒石。
- 觉4→觉5：400碎片（4本体等价值）+ 4觉醒石。
- 觉5→超1：300碎片（3本体等价值）+ 3超限石。
- 超1→超2：300碎片（3本体等价值）+ 3超限石。
- 超2→超3：400碎片（4本体等价值）+ 4超限石。
- 超3→超4：400碎片（4本体等价值）+ 4超限石。
- 超4→超5：500碎片（5本体等价值）+ 5超限石。

## 合计核对

- 觉0→觉5：200 + 200 + 300 + 300 + 400 = 1400碎片（14本体等价值），14觉醒石。
- 觉5→超5：300 + 300 + 400 + 400 + 500 = 1900碎片（19本体等价值），19超限石。
- 觉0→超5：3300碎片（33本体等价值），14觉醒石 + 19超限石，与原表总计一致。
- 若另含首次获得觉0：3400碎片等价值（34本体等价值），石头仍为14觉醒石 + 19超限石。这是上述数据推算值。

## 拜访计算

每次拜访获得5碎片，每天最多3次。所需次数为碎片缺口除以5并向上取整，所需天数为次数除以3并向上取整。缺6碎片需2次（1天），缺16碎片需4次（2天，第二天拜访1次）。觉醒石和超限石的缺口单独计算。

原表「天数加碎片」使用整天加剩余碎片的写法。例如「13天加5碎片」相当于40次拜访，按本工具显示为14天，最后一天1次。
