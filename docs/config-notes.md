# 配置备忘

## 卡池与兑换进度

- 已抽抽数：免费途径上方的独立输入区；总计抽数 = 已抽抽数 + 计划抽数。
- 已抽记录自动保存；清空免费或礼包时保留，全部重置时清零。
- 总计花费与计划单抽均价只计算当前方案，已抽的历史花费不作估计。
- 钻石兑换：500钻石 = 1抽，可选择0–50抽（最多25000钻石），默认兑换50抽。
- 0元签到：7天，每天1抽；填写已签到天数，剩余天数 = 7 - 已签到天数，按剩余可领取抽数计入方案。
- 88元签到：保持总计50抽，按天发放规则待补充。
- 商店表格的600抽专武行始终高亮，达成状态随总抽数更新。
